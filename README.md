Rule-Based AI Chatbot

A simple Rule-Based AI Chatbot built with Python that uses predefined rules and conditional logic to simulate conversations. The chatbot analyzes user input, matches keywords, and returns appropriate responses without using machine learning models.

📌 Project Overview

This project demonstrates the fundamentals of Artificial Intelligence by implementing a chatbot that responds to user queries based on predefined rules. It is designed to showcase decision-making, pattern matching, and conversational flow using Python.

✨ Features
Interactive command-line chatbot
Keyword-based response matching
Rule-based conversation logic
Handles greetings and common questions
Easy to modify and extend
Beginner-friendly Python project

🚀 How to Run
Clone the repository.
git clone https://github.com/your-username/Rule-Based-AI-Chatbot.git
Navigate to the project folder.
cd Rule-Based-AI-Chatbot
Install Jupyter Notebook (if not installed).
pip install notebook
Launch Jupyter Notebook.
jupyter notebook
Open Rule-Based AI Chatbot.ipynb and run all cells.
